# Биржа — игра для друзей

Браузерная многопользовательская игра в духе монополии с акциями. Играют от 2 до 5 человек, каждый со своего компьютера, по ссылке на комнату.

## Что уже работает

- Комнаты по ссылке: один создаёт комнату, остальные заходят по присланной ссылке. Если обновить страницу или пропал интернет, игрок вернётся на своё место.
- Поле на 32 клетки: 20 компаний в 8 отраслях, «Новости», «Налог», «Сделка с банком» и четыре угла (Старт, Инсайдер, Биржевые торги, Налоговая проверка).
- Доли по 10%. У банка один игрок покупает не больше 20% одной компании, остальное только у других игроков.
- Аренда 5% от цены компании, делится между владельцами по их долям. У кого больше 50%, тот получает двойную аренду.
- Торговля: свою долю можно выставить по любой цене, а купить чужое предложение можно в свой ход. Купленное в этот ход продать нельзя.
- Секретные новости: выбираете одну из трёх, она срабатывает через 2 круга. Остальные игроки видят только отрасль, а угол «Инсайдер» показывает все секретные новости.
- Лоббирование: стоит 3% от цены, срабатывает при 4–6 на кубике, меняет цену на ±15%.
- Банкротство: если нечем платить, доли продаются банку автоматически.
- Старт со 150 000 $, зарплата 30 000 $ за проход через «Старт».
- Победа: 400 000 $ наличными или 500 000 $ капитала в начале своего хода. Если время партии вышло, побеждает самый богатый.
- На ход 90 секунд, все видят обратный отсчёт. Кто не успел, за того кубики бросаются сами, и ход заканчивается. Это же спасает, если игрок ушёл.
- Живой рынок: в начале каждого круга все цены сами немного меняются (в среднем рынок растёт на 3% за круг). С шансом 40% случается общее событие рынка, например кризис или бум отрасли.
- Анимация: кубики крутятся, фишка идёт по клеткам и подпрыгивает на каждой.
- Дубли: одинаковые кубики дают ещё один ход с новыми 90 секундами. Третий дубль подряд: фишка не идёт, игрок выбирает секретную новость, и ход заканчивается.
- «Старт» в левом верхнем углу, фишки идут по часовой стрелке.
- Поле тянется под размер экрана.

## Как запустить у себя на компьютере

1. Установите Node.js версии 18 или новее с сайта https://nodejs.org (кнопка LTS).
2. Распакуйте архив в любую папку.
3. Откройте в этой папке терминал. На Windows: зайдите в папку, кликните по адресной строке проводника, напишите `cmd` и нажмите Enter.
4. Выполните по очереди:
   ```
   npm install
   npm start
   ```
5. Откройте в браузере http://localhost:3000.

Проверить игру в одиночку можно так: откройте вторую вкладку в режиме инкогнито и зайдите по ссылке комнаты как второй игрок.

Друзья в той же Wi-Fi-сети могут подключиться по адресу `http://ВАШ-IP:3000`. Узнать IP на Windows можно командой `ipconfig`, строка «IPv4». Друзьям из других мест нужен хостинг, он описан ниже.

## Как выложить в интернет бесплатно (Render)

1. Зарегистрируйтесь на https://github.com и создайте новый репозиторий: кнопка New, любое имя, например `birzha`.
2. На странице репозитория нажмите «uploading an existing file» и перетащите туда все файлы из архива. Папку `node_modules`, если она появилась, загружать не нужно. Нажмите «Commit changes».
3. Зарегистрируйтесь на https://render.com через аккаунт GitHub.
4. Нажмите New → Web Service и выберите свой репозиторий.
5. Заполните настройки:
   - Build Command: `npm install`
   - Start Command: `npm start`
   - Тариф: Free
6. Нажмите Create Web Service и подождите пару минут. Render выдаст ссылку вида `https://birzha-xxxx.onrender.com`. Откройте её, создайте комнату и отправьте друзьям ссылку из лобби.

Особенности бесплатного тарифа Render:
- После 15 минут без игроков сервер засыпает, и первое открытие потом занимает около минуты.
- При перезапуске сервера текущие партии пропадают, потому что игры хранятся в памяти.

## Где менять баланс

Все числа лежат в начале файла `game.js`, в блоке `CONFIG`: стартовые деньги, зарплата за круг, цели победы, время на ход, колебания и общий рост рынка, шанс события рынка, аренда, лимит покупки у банка, цена и сила лоббирования, суммы на клетках налога и сделки с банком, максимум игроков. Цены компаний задаются там же, в списке `BOARD`, а события рынка — в списке `MARKET_EVENTS`.

После изменений перезапустите сервер: Ctrl+C, затем `npm start`. Если игра выложена на Render, загрузите изменённый файл в GitHub, и Render обновится сам.

Команда `npm test` прогоняет 300 партий ботами и проверяет, что правила не ломаются. Она же показывает, сколько ходов на одного игрока в среднем длится партия. При текущих настройках боты доходят до цели примерно за 27 ходов на игрока, то есть 30–45 минут живой игры.

## Файлы

- `game.js` — все правила игры.
- `server.js` — сервер: раздаёт страницу и держит комнаты.
- `public/index.html`, `public/style.css`, `public/client.js` — то, что видит игрок в браузере.
- `test/simulate.js` — пробные партии ботами.
